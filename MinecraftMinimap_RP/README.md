# Survival AI Minimap Icons — Resource Pack 1.2.0

Contains `font/glyph_E2.png`, a 16×16-cell Bedrock glyph sheet with 30 original pixel-art icons.

| Glyph range | Content |
|---|---|
| U+E200–U+E213 | Player, villager, creeper, zombie, skeleton, spider, cow, pig, sheep, chicken, horse, wolf, enderman, witch, slime, bee, iron golem, rabbit, fox, hostile |
| U+E214–U+E21D | Diamond, iron, gold, emerald, copper, coal, redstone, lapis, ancient debris, quartz |

The icons are original pixel-art assets designed for this add-on, using Minecraft Bedrock's documented custom glyph-sheet mechanism. Mojang's public Bedrock sample files were consulted as the format/reference source; vanilla Mojang texture files are not bundled here.

References:
- https://github.com/Mojang/bedrock-samples
- https://wiki.bedrock.dev/text/custom-emojis

The custom glyph atlas is used by the Behavior Pack to draw tiny creature and ore pictures in the in-game action bar. Enable both packs (the BP manifest declares the RP dependency).
